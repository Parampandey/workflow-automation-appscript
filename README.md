# Automated Workflow System using Google Apps Script

A trigger-based workflow automation system built on Google Apps Script that sends real-time email notifications and generates automated daily summary reports from Google Sheets.

## 🚀 Features
- Real-time email alerts on new spreadsheet entries
- Automated daily summary reports using scheduled triggers
- Data validation to reduce manual errors
- Event-driven architecture using Apps Script triggers

## 🛠 Tech Stack
- Google Apps Script
- Google Sheets API
- JavaScript
- Trigger-based automation

## 📊 System Workflow
1. User enters data in Google Sheet
2. Trigger activates Apps Script function
3. Email notification is sent automatically
4. Daily report is generated via time trigger

1. Open Google Sheet
2. Go to Extensions → Apps Script
3. Paste Code.gs content
4. Set triggers
5. Start entering data
